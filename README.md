# ConsoleCalculatorQt

Лабораторная работа №1 «Консольный калькулятор с метаобъектами».
Вариант: **продвинутый уровень, №5 — асинхронный калькулятор с QFuture**.

Все арифметические операции выполняются в фоновых потоках через `QtConcurrent::run()`,
результат приходит в главный поток сигналом `resultReady`. Пока операция считается,
можно вводить следующие команды: несколько операций выполняются параллельно.

## Пример работы

```
> delay 1000
Задержка: 1000 мс
> add 5 3
Запущено: 5 + 3
> mul 4 2.5
Запущено: 4 * 2.5
> div 1 0
Ошибка: Деление на ноль невозможно!
>
Результат: 5 + 3 = 8
>
Результат: 4 * 2.5 = 10
> quit
До свидания!
```

## Команды

| Команда        | Описание                                                 |
|----------------|----------------------------------------------------------|
| `add <a> <b>`  | сложение                                                 |
| `sub <a> <b>`  | вычитание                                                |
| `mul <a> <b>`  | умножение                                                |
| `div <a> <b>`  | деление (с проверкой деления на ноль)                    |
| `reset`        | сброс результата в 0                                     |
| `delay <мс>`   | искусственная задержка операций (по умолчанию 2000 мс)   |
| `help`         | справка                                                  |
| `quit`, `exit` | выход (с ожиданием незавершённых операций)               |

## Архитектура

```
 поток ввода            главный поток (app.exec())             пул потоков
 ConsoleReader          Calculator / main                      QtConcurrent
 ─────────────          ─────────────────────────              ────────────
 readLine()  ──lineRead──▶ processLine()
                          calc.add(5, 3) ──QtConcurrent::run──▶ sleep + 5 + 3
                          ◀─ QFutureWatcher::finished ───────── готово
                          emit resultReady("5 + 3", 8)
                          → вывод в консоль
```

- **`Calculator`** (`calculator.h/.cpp`) — наследник `QObject`. Слоты `add`, `subtract`,
  `multiply`, `divide` запускают вычисление через `QtConcurrent::run()` и сразу
  возвращают управление. `QFutureWatcher` следит за `QFuture` и по сигналу `finished`
  калькулятор излучает `resultReady(expression, result)`.
  Сигналы: `operationStarted`, `resultReady`, `errorOccurred`, `allFinished`.
- **`ConsoleReader`** (`consolereader.h/.cpp`) — наследник `QThread`. Блокирующее
  чтение stdin вынесено в отдельный поток, иначе главный поток не мог бы крутить
  цикл событий и получать сигналы из фоновых потоков. Строки передаются сигналом `lineRead`.
- **`main.cpp`** — соединяет объекты через `QObject::connect` (синтаксис указателей
  на методы), разбирает команды и запускает `app.exec()`.

Все ошибки (деление на ноль, неверный формат, нечисловые операнды, неизвестная
команда, отрицательная задержка) сообщаются сигналом `errorOccurred`.

## Сборка и запуск

Требуется Qt 6 (модули core, concurrent, testlib) и компилятор с поддержкой C++17.

**Qt Creator:** открыть `ConsoleCalculator.pro` → выбрать комплект (например,
Desktop Qt 6 MinGW 64-bit) → Собрать → Запустить.

**Командная строка** (пути Qt должны быть в `PATH`):

```
mkdir build && cd build
qmake ../ConsoleCalculator.pro
mingw32-make
release\ConsoleCalculator.exe
```

## Тесты

Открыть в Qt Creator `tests/tests.pro` и запустить, либо:

```
mkdir build-tests && cd build-tests
qmake ../tests/tests.pro
mingw32-make
release\CalculatorTests.exe
```

Тесты используют `QSignalSpy` и проверяют: результаты всех операций, то, что результат
приходит асинхронно (не сразу после вызова слота), ошибку деления на ноль, сброс,
счётчик фоновых операций и сигнал `allFinished`, параллельное выполнение операций.
